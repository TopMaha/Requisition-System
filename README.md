| ไฟล์ | คำอธิบาย |
|------|----------|
| `index.html` | หน้าเว็บหลัก (เปิดในเบราว์เซอร์ได้เลย) |

## วิธีติดตั้ง (ครั้งแรก)

### ขั้นที่ 1 — ติดตั้ง Node.js และ Wrangler
```
npm install -g wrangler
```

### ขั้นที่ 2 — รัน deploy.bat
ดับเบิลคลิก `deploy.bat` ทำตามขั้นตอน:
1. Login Cloudflare
2. สร้าง D1 database → copy `database_id`
3. วาง `database_id` ใน `wrangler.toml`
4. Deploy Worker

### ขั้นที่ 3 — ตั้งค่าใน index.html
1. เปิด `index.html` ในเบราว์เซอร์
2. กดปุ่ม ⚙️ มุมบนขวา
3. ใส่ Worker URL (เช่น `https://requisition-system.xxx.workers.dev`)
4. ใส่ Admin Password (default: `admin1234`)
5. กดบันทึก

## วิธีใช้งาน

### สำหรับพนักงาน (เบิกของ) — ไม่ต้องหา Item เอง
1. เข้าสู่ระบบด้วยรหัสพนักงาน
2. แท็บ **📷 เบิกของ** → ถ่ายรูปของที่ต้องการเบิก (สูงสุด 4 รูป — เบิกเป็นชุดถ่ายรวมในรูปเดียวได้)
3. กรอกแค่ 3 อย่าง: **จำนวน**, **นำไปใช้เครื่องไหน**, **จุดประสงค์**
4. กด **"ส่งคำขอเบิกให้ Admin"** → ติดตามสถานะที่แท็บ **📋 ประวัติ**

### สำหรับ Admin (ตรวจสอบ + อนุมัติ)
1. แท็บ **🔧 Admin** → การ์ด **📥 คำขอเบิกรอตรวจสอบ** (ตัวเลขแดงบนแท็บ = จำนวนที่รอ)
2. กด **🔍 ตรวจสอบ & ใส่ Item** → แตะรูปเพื่อดูขนาดใหญ่ (ซูม/เลื่อน/หมุนได้)
3. ค้นหาแล้วกด **＋ เพิ่ม** Item Part — **1 รูปเพิ่มได้หลาย Item** (กรณีเบิกเป็นชุด)
   - ถ้ายังไม่มีในระบบ กด **"เพิ่ม Item ใหม่จากรูปนี้"**
4. เลือกผล: **อนุมัติ + จ่ายของ (ตัด Stock ทันที)** / **อนุมัติ (จ่ายทีหลัง)** / **ไม่อนุมัติ**
5. ดูการ์ด **📊 ยอดเบิก & คาดการณ์ของหมด** — เบิกไปเท่าไร และ Item ไหนจะหมดในกี่วัน

## ทำไมเปลี่ยนจาก AI มาเป็น Admin ระบุ Item

ระบบเดิมใช้ AI จับคู่รูปกับ Item แต่รูปที่ถ่ายไม่ชัด และต้องใช้รูปจำนวนมากสอน AI จึงเปลี่ยนเป็น:
- พนักงานไม่ต้องเลือก Item เอง → **ไม่กด Item ผิด / ไม่ต้องหา Item**
- Admin ต้องตรวจทุกใบก่อนจ่าย และเห็นยอดเบิก + คาดการณ์ของหมด → **ไม่ขาดแคลน**
- ไม่เรียก AI ตอนเบิกและตอนเพิ่ม Item → **ลดการคำนวณ/พื้นที่**

> Endpoint AI เดิม (`/api/match` ฯลฯ) ยังอยู่ใน `worker.js` แต่หน้าเว็บไม่เรียกใช้แล้ว

## Database Schema

- `categories` — หมวดหมู่อุปกรณ์
- `items` — รายการอุปกรณ์/อะไหล่
- `requisitions` — ใบเบิก (ผู้เบิก, เครื่อง, จุดประสงค์, จำนวนที่ขอ, สถานะ)
- `requisition_photos` — รูปที่พนักงานถ่าย (เก็บใน R2)
- `requisition_items` — Item Part ที่ Admin ระบุ (1 ใบเบิกมีได้หลาย Item)
- `stock_movements` — ประวัติการเคลื่อนไหว Stock (ใช้คำนวณยอดเบิก)

ตาราง/คอลัมน์ใหม่ถูกสร้างอัตโนมัติเมื่อ Worker ทำงานครั้งแรก (ไม่ต้องรัน SQL เอง)

## เปลี่ยน Admin Password

แก้ในไฟล์ `wrangler.toml`:
```toml
[vars]
ADMIN_PASSWORD = "รหัสใหม่"
```
แล้วรัน `wrangler deploy` อีกครั้ง
